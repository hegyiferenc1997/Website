## What you will learn

- the difference between **UX** (user experience) and **UI** (user interface),
- what **usability** is and what it consists of,
- why good design pays off for a company.

## UX and UI

- **UI** (User Interface): what the user **sees and touches** – buttons, menus, colours, fonts, icons, layout.
- **UX** (User Experience): **everything** the user **goes through** while using the product – do they find what they look for, how fast, how annoyed are they, do they come back.

An analogy: a spoon's UI is its shape and material; its UX is whether it is comfortable to eat soup with. A beautiful interface can still give a bad experience if you can't find the “Pay” button.

## Usability

According to Jakob Nielsen, **usability** has five components:

| Component        | Question                                                        |
| ---------------- | --------------------------------------------------------------- |
| **learnability** | how easily does a new user cope the first time?                 |
| **efficiency**   | how fast does someone who knows it complete the task?           |
| **memorability** | after not using it for a while, how easily do they get back?    |
| **errors**       | how many mistakes do they make, and how easily do they recover? |
| **satisfaction** | how pleasant is it to use?                                      |

## Why does it matter?

- Users decide **in moments**: if a site is slow or confusing, they move on to a competitor.
- Fixing a problem is cheapest in the **design** phase; in the finished product it costs many times more.
- Good UX means **fewer support calls**, more purchases and more loyal users.

## Good and bad examples

| Bad                                                         | Good                                                              |
| ----------------------------------------------------------- | ----------------------------------------------------------------- |
| a form that clears every field after submit if one is wrong | marks the wrong field in red and keeps the rest                   |
| “An error occurred (0x80070005)”                            | “You don't have access to this folder. Ask the owner for access.” |
| tiny buttons close together on mobile                       | touch targets of at least about 44×44 pixels                      |
| all text the same size                                      | clear headings, a highlighted main button                         |

## Summary

- UI = what you see and touch; UX = the whole experience during use.
- Usability: learnability, efficiency, memorability, errors, satisfaction.
- Good UX saves money and keeps users.
