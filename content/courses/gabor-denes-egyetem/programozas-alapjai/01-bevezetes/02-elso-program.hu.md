title: Az első Python program
summary: A Python telepítése, a fejlesztőkörnyezet és a „Hello, World!”.
minutes: 15
---

A Python letölthető a [python.org](https://www.python.org/downloads/) oldalról. Telepítés után egy szerkesztőben (pl. VS Code a Python bővítménnyel) hozz létre egy `hello.py` fájlt:

```python
print("Hello, World!")
```

Futtatás a terminálból:

```bash
python hello.py
```

A `print` egy beépített **függvény**: amit a zárójelek közé írsz, azt kiírja a képernyőre. A szöveget idézőjelek közé kell tenni.

> Tipp: a Python **interaktív módban** is használható. Írd be a terminálba, hogy `python`, és soronként próbálhatod ki az utasításokat.
