---
title: Your first Python program
summary: Installing Python, the editor, and “Hello, World!”.
---

Download Python from [python.org](https://www.python.org/downloads/). After installing, create a file called `hello.py` in an editor (for example VS Code with the Python extension):

```python
print("Hello, World!")
```

Run it from the terminal:

```bash
python hello.py
```

`print` is a built-in **function**: it shows whatever you put between the parentheses. Text has to be in quotes.

> Tip: Python also has an **interactive mode**. Type `python` in the terminal and try statements line by line.
