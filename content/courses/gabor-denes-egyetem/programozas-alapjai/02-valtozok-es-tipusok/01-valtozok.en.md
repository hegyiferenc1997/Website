---
title: Variables and assignment
summary: How to store values under a name.
---

A **variable** is a name that refers to a value. Assign a value with `=`:

```python
age = 19
name = "Anna"
age = age + 1    # a variable can be overwritten
print(name, age) # Anna 20
```

Naming rules:

- starts with a letter or `_`, followed by letters, digits or `_`,
- case matters (`age` ≠ `Age`),
- by convention lowercase with underscores between words: `average_score`.
