## Amit ebben a leckében megtanulsz

- mit jelent az **üzleti modell**,
- mi a **Business Model Canvas** kilenc építőeleme,
- hogyan töltsd ki egy informatikai termékre.

## Mi az üzleti modell?

**Alexander Osterwalder** meghatározása szerint az **üzleti modell** azt írja le, hogy egy szervezet **hogyan teremt, juttat el a vevőhöz és tart meg értéket** (azaz hogyan keres pénzt). Egy jó termék is megbukhat rossz üzleti modellel – és egy átlagos termék is sikeres lehet egy ügyes modellel.

## Az üzleti modell vászon (Business Model Canvas)

Osterwalder és Pigneur (2010) egyetlen lapon, **kilenc építőelemmel** ábrázolja a modellt:

```text
┌────────────┬────────────┬────────────┬────────────┬────────────┐
│ Kulcs-     │ Kulcs-     │            │ Ügyfél-    │ Ügyfél-    │
│ partnerek  │ tevékeny-  │  Érték-    │ kapcsolatok│ szegmensek │
│   (8)      │ ségek (7)  │  ajánlat   │    (4)     │    (1)     │
│            ├────────────┤    (2)     ├────────────┤            │
│            │ Kulcs-     │            │ Csatornák  │            │
│            │ erőforrások│            │    (3)     │            │
│            │   (6)      │            │            │            │
├────────────┴────────────┴─────┬──────┴────────────┴────────────┤
│        Költségszerkezet (9)   │         Bevételi források (5)  │
└───────────────────────────────┴────────────────────────────────┘
```

| #   | Elem                   | Kérdés                                                                |
| --- | ---------------------- | --------------------------------------------------------------------- |
| 1   | **Ügyfélszegmensek**   | Kiknek teremtünk értéket? Kik a legfontosabb vevőink?                 |
| 2   | **Értékajánlat**       | Milyen problémát oldunk meg, milyen igényt elégítünk ki?              |
| 3   | **Csatornák**          | Hogyan érjük el az ügyfeleket (értékesítés, szállítás)?               |
| 4   | **Ügyfélkapcsolatok**  | Milyen kapcsolatot építünk velük (önkiszolgáló, személyes, közösség)? |
| 5   | **Bevételi források**  | Miért és hogyan fizetnek az ügyfelek?                                 |
| 6   | **Kulcserőforrások**   | Mire van szükségünk (emberek, technológia, szellemi tulajdon, pénz)?  |
| 7   | **Kulcstevékenységek** | Mit kell a legjobban csinálnunk (fejlesztés, üzemeltetés, marketing)? |
| 8   | **Kulcspartnerek**     | Kik a beszállítóink, szövetségeseink?                                 |
| 9   | **Költségszerkezet**   | Melyek a legnagyobb költségeink?                                      |

> A jobb oldal (1–5) az **érték és a bevétel** oldala (a vevő felé), a bal oldal (6–9) a **hatékonyság és a költség** oldala (a működés). A kitöltést mindig az **ügyfélszegmensekkel és az értékajánlattal** kezdjük.

## Példa: egy egyetemi tanulást segítő webes platform

| Elem               | Tartalom                                                  |
| ------------------ | --------------------------------------------------------- |
| Ügyfélszegmensek   | mérnökinformatikus hallgatók; később egyetemek            |
| Értékajánlat       | a tantárgyakhoz igazított, interaktív leckék és feladatok |
| Csatornák          | weboldal, közösségi média, hallgatói szervezetek          |
| Ügyfélkapcsolatok  | önkiszolgáló, automatikus visszajelzés, közösségi fórum   |
| Bevételi források  | félévenkénti előfizetés                                   |
| Kulcserőforrások   | tananyag, platform kódja, szerzők                         |
| Kulcstevékenységek | tartalomkészítés, fejlesztés, marketing                   |
| Kulcspartnerek     | felhőszolgáltató, fizetési szolgáltató, oktatók           |
| Költségszerkezet   | fejlesztői bérek, tárhely, fizetési díjak, marketing      |

## Kapcsolódó eszköz: értékajánlat vászon

Az **értékajánlat vászon** (_Value Proposition Canvas_) a 1. és a 2. elemet bontja tovább: az ügyfél **feladatait, fájdalmait és nyereségeit** állítja szembe a termék **fájdalomcsillapítóival és nyereségteremtőivel**. Ha a kettő illeszkedik, megvan a **termék–piac illeszkedés** (_product–market fit_).

## Összefoglalás

- Az üzleti modell leírja, hogyan teremt, juttat el és tart meg értéket a szervezet.
- A Business Model Canvas kilenc eleme: ügyfélszegmensek, értékajánlat, csatornák, ügyfélkapcsolatok, bevételi források, kulcserőforrások, kulcstevékenységek, kulcspartnerek, költségszerkezet.
- A kitöltés az ügyfelekkel és az értékajánlattal kezdődik.
