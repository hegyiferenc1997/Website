## Amit ebben a leckében megtanulsz

- hogyan méred fel, mennyire **elkötelezettek** az érintettek,
- hogyan tervezd meg a **bevonásukat**,
- miért **állnak ellen** az emberek a változásnak, és mit tehetsz,
- mik az **elvszerű tárgyalás** alapjai.

## A bevonás szintjei

A PMBOK öt szintet különböztet meg:

| Szint                       | Jellemző                                      |
| --------------------------- | --------------------------------------------- |
| **nem tudatos** (_unaware_) | nem tud a projektről és a hatásairól          |
| **ellenálló** (_resistant_) | tud róla, de ellenzi a változást              |
| **semleges** (_neutral_)    | tud róla, de se nem támogatja, se nem ellenzi |
| **támogató** (_supportive_) | tud róla, és támogatja                        |
| **vezető** (_leading_)      | tud róla, és aktívan dolgozik a sikeréért     |

## A bevonási mátrix

Minden kulcsérintettnél jelöljük a **jelenlegi** (**C**, _current_) és a **kívánt** (**D**, _desired_) szintet. A kettő közötti különbség mutatja, hol kell tennünk:

| Érintett               | Nem tudatos | Ellenálló | Semleges | Támogató | Vezető |
| ---------------------- | ----------- | --------- | -------- | -------- | ------ |
| szponzor (rektor)      |             |           |          | C        | D      |
| tanulmányi osztály     |             | C         |          | D        |        |
| oktatók                | C           |           | D        |          |        |
| hallgatói önkormányzat |             |           | C        | D        |        |

Ebben a példában a **tanulmányi osztály** a legnagyobb kihívás: ellenállóból támogatóvá kell válnia – és nagy a befolyása.

## Bevonási stratégiák

- **Tájékoztatás**: rendszeres, érthető információ a projekt céljáról és hatásairól (a „nem tudatos” szintről kimozdít).
- **Konzultáció**: véleménykérés, kérdőív, interjú – a visszajelzésre válaszolni is kell!
- **Bevonás**: részvétel workshopokban, tesztelésben, kulcsfelhasználói szerep.
- **Együttműködés**: közös döntéshozatal, felelősség megosztása.
- **Felhatalmazás**: az érintett maga vezeti a változás egy részét (ő lesz a „nagykövet”, a _change champion_).

## Az ellenállás okai és kezelése

Az emberek ritkán magát a változást utálják – inkább azt, amit **elveszíthetnek** általa. Gyakori okok:

- **félelem** az ismeretlentől, a munkahely vagy a státusz elvesztésétől,
- **több munka** az átállás idején,
- **kimaradás** a döntésekből („rólunk, nélkülünk”),
- **rossz tapasztalat** korábbi projektekkel,
- az előnyök **nem világosak**.

Kezelése:

1. **meghallgatni** – az ellenállás gyakran jogos, hasznos információt hordoz,
2. a **„miért?”** elmagyarázása, a személyes előnyök bemutatása,
3. **bevonás** a tervezésbe és a tesztelésbe,
4. **képzés** és támogatás az átállás idején,
5. **gyors sikerek** (_quick wins_) megmutatása.

A szervezeti változáskezelésről a 14. témakörben még lesz szó (Kotter, ADKAR).

## Elvszerű tárgyalás

A **harvardi tárgyalási módszer** (Fisher és Ury: „A sikeres tárgyalás alapjai”, 1981) négy elve:

1. **Válaszd szét az embert és a problémát** – keményen a problémával, kedvesen az emberrel.
2. **Az érdekekre koncentrálj, ne az álláspontokra** – az „ezt akarom” mögött ott a „miért”.
3. **Keress kölcsönösen előnyös megoldásokat** – előbb gyűjts lehetőségeket, csak utána dönts.
4. **Ragaszkodj objektív kritériumokhoz** – piaci ár, szabvány, adat.

Fontos fogalom a **BATNA** (_Best Alternative To a Negotiated Agreement_): a legjobb alternatívád, ha nem jön létre megállapodás. Minél jobb a BATNA-d, annál erősebb a tárgyalási pozíciód; olyan megállapodást, amely rosszabb a BATNA-dnál, nem érdemes elfogadni.

## Összefoglalás

- Bevonási szintek: nem tudatos, ellenálló, semleges, támogató, vezető.
- Bevonási mátrix: jelenlegi (C) és kívánt (D) szint – a különbség a teendő.
- Stratégiák: tájékoztatás, konzultáció, bevonás, együttműködés, felhatalmazás.
- Ellenállás: meghallgatás, „miért?”, bevonás, képzés, gyors sikerek.
- Elvszerű tárgyalás: ember és probléma szétválasztása, érdekek, kölcsönös előny, objektív kritériumok; BATNA.
